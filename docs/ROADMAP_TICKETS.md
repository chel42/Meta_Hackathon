# Backlog TRAUNES AI — Tickets Backend et Frontend

Backlog consolidé à partir de [BACKEND.md](./BACKEND.md), [FRONTEND.md](./FRONTEND.md) et [AGENTS.md](./AGENTS.md). Les identifiants et priorités reprennent les spécifications du projet.

- **P0** : nécessaire au parcours Beta.
- **P1** : complément prévu après le parcours P0.
- Les estimations sont indicatives ; les dépendances indiquent l'ordre d'intégration, pas l'obligation de travailler en série lorsque les tickets sont indépendants.
- Les sous-tâches **A-01 à A-09** détaillent le travail IA des tickets Backend parents, elles ne remplacent pas ces tickets.
